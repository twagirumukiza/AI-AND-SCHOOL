TRIBUNE TWAGIRUMUKIZA
====================

Fichiers : index.html + hero.jpg + learning.jpg + critical.jpg + og-image.jpg.

Déploiement GitHub Pages :
1. Créez un dépôt GitHub nommé "School-and-AI" (ou adaptez les URL dans index.html
   si vous utilisez un autre nom de dépôt).
2. Copiez les 5 fichiers à la racine du dépôt (remplacez les anciens hero.svg,
   learning.svg, critical.svg, og-image.png s'ils sont encore présents).
3. Activez Settings > Pages > Deploy from branch.
4. Ouvrez l'URL GitHub Pages.

Illustrations
-------------
Les 3 illustrations SVG ont été remplacées par vos photos :
- hero.jpg      -> image d'ouverture (classe, éducation aux réseaux sociaux)
- learning.jpg  -> section "personnalisation de l'apprentissage" (labo, réalité augmentée)
- critical.jpg  -> section "esprit critique" (scientifique face à des données confuses)
og-image.jpg (aperçu de partage social) a aussi été régénérée à partir de hero.jpg,
avec surimpression du titre, pour rester cohérente avec le reste du site.

La page est autonome : FR / EN / 中文 (détection automatique de la langue du
navigateur, mémorisée ensuite), clair/sombre (mémorisé), taille de caractères,
menu responsive, barre de progression de lecture, partage social avec vos
propres icônes (répétées en bas de page), bouton d'intégration iframe et liens auteur.

Note : les boutons de partage ouvrent les services sociaux. WeChat copie le lien afin de
laisser l'utilisateur choisir où le publier. LinkedIn utilise le mécanisme de partage d'URL.
